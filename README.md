# 江格尔史诗 · 宝木巴的梦境守护

创闯怆团队以蒙古族英雄史诗《江格尔》为灵感设计的中文网页桌游。玩家在四幕梦境中使用叙事标签、角色技能和修复令牌，补全史诗并在终局指认影子阵营。

**[在线开始单人游戏](https://heyanfeng-barca.github.io/jangar-epic/)** · [下载完整项目 ZIP](https://github.com/Heyanfeng-BARCA/jangar-epic/archive/refs/heads/main.zip)

## 在线单人游玩

打开网页，点击「开启梦境」，选择 6、7 或 8 个席位和角色。其余席位由电脑控制。游戏内的「玩法说明」介绍四幕流程、角色技能和结局判定。允许本地存储时，可以在同一浏览器和网址继续上一局。

离线游玩时，下载并完整解压项目 ZIP，双击 [docs/index.html](docs/index.html)。网页、规则和图片已包含在项目内，无需安装运行环境。

## 局域网联机

1. 房主安装 Node.js 18 或更高版本，然后在项目根目录运行下方命令。Windows 也可以双击 [启动联机.cmd](启动联机.cmd)。项目使用 Node.js 内置模块，无需安装依赖。
2. 在浏览器打开终端显示的本机地址，默认是 `http://localhost:8060/`。点击「联机房间」，创建房间并设置口令。
3. 将终端显示的局域网地址、房间号和口令交给同一网络内的好友。空席由电脑补齐。支持文字讨论、影子密语及在原浏览器中重连。关闭服务会结束内存里的房间。

```sh
node server.cjs
```

GitHub Pages 提供静态的在线单人版。多人房间由房主本地运行的 Node.js 服务提供。如果好友无法加入，请确认两台设备在同一局域网，并使用终端显示的局域网地址。

## 游戏规则与参考资料

每局从 60 点史诗完整度和每位玩家 10 点信念开始。每轮提交一个标签，联机时在真人完成操作或倒计时结束后推进。最佳叙事优先考虑直面恐惧，其次比较有效文本长度。最终指认、标签侵蚀和并列判定见游戏内「玩法说明」。结果页按实际对局计算，图鉴中的结局设计图保留了原图示例。
